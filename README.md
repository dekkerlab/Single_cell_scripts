#Single-cell-folding-variability paper

Code accompanying the manuscript:   Work in Progress

The repository is organized into four directories: Hi-C_Fig1_3, Image_Fig2_3_4 and RNA_Fig3_6, and scRNA. These directories contain several Jupyter notebooks and .sh scripts, where each .sh scripts are used to deal the original fastq data and each Jupyter notebook reproduces the panels for one main figure and its associated Extended Data figure. 

##Data availability

•	Sequencing data (droplet scHi-C, plate-based scHi-C, scRNA-seq and bulk-Hi-C): GEO accession are: GSE339429 (droplet scHi-C), GSE339449, GSE341341 (plate-based scHi-C), GSE339418 (scRNA-seq), and GSE339386 (H1 cell-cycle bulk Hi-C).
